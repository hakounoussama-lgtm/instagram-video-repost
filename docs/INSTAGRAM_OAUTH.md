# Instagram OAuth Setup Guide\n\n## الخطوات:\n\n### 1. إنشاء تطبيق Instagram\n1. اذهب إلى https://developers.facebook.com/\n2. قم بإنشاء تطبيق جديد\n3. اختر نوع التطبيق: Business\n4. أضف منتج Instagram Graph API\n\n### 2. الحصول على Credentials\n- **Client ID**: معرّف التطبيق\n- **Client Secret**: سر التطبيق\n\n### 3. تكوين Redirect URI\nفي إعدادات التطبيق، أضف:\n```\nhttp://localhost:5000/api/instagram/callback\n```\n\nللإنتاج:\n```\nhttps://yourdomain.com/api/instagram/callback\n```\n\n### 4. إضافة المتغيرات للـ .env\n```bash\nINSTAGRAM_CLIENT_ID=your_client_id\nINSTAGRAM_CLIENT_SECRET=your_client_secret\nINSTAGRAM_REDIRECT_URI=http://localhost:5000/api/instagram/callback\n```\n\n### 5. API الأساسي\n\n#### الحصول على رابط التفويض\n```bash\nPOST /api/instagram/authorize\nAuthorization: Bearer YOUR_JWT_TOKEN\n\nResponse:\n{\n  \"success\": true,\n  \"auth_url\": \"https://api.instagram.com/oauth/authorize?...\"\n}\n```\n\n#### الحصول على الحسابات\n```bash\nGET /api/instagram/accounts\nAuthorization: Bearer YOUR_JWT_TOKEN\n\nResponse:\n{\n  \"success\": true,\n  \"accounts\": [\n    {\n      \"id\": 1,\n      \"instagram_id\": \"123456\",\n      \"instagram_username\": \"myusername\",\n      \"instagram_name\": \"My Name\",\n      \"followers_count\": 1000,\n      \"is_primary\": true,\n      \"is_active\": true,\n      \"connected_at\": \"2026-06-12T15:30:00\"\n    }\n  ]\n}\n```\n\n#### تحديث الـ Token\n```bash\nPOST /api/instagram/accounts/{account_id}/refresh-token\nAuthorization: Bearer YOUR_JWT_TOKEN\n```\n\n#### قطع الاتصال\n```bash\nPOST /api/instagram/accounts/{account_id}/disconnect\nAuthorization: Bearer YOUR_JWT_TOKEN\n```\n\n## المميزات الأمنية\n\n✅ **OAuth 2.0**: تسجيل دخول آمن بدون تخزين كلمات المرور\n✅ **Encrypted Tokens**: تشفير الـ access tokens\n✅ **Token Refresh**: تحديث تلقائي للـ tokens\n✅ **State Protection**: حماية ضد CSRF attacks\n✅ **Long-lived Tokens**: صلاحية 60 يوم\n\n## حالات الاستخدام\n\n1. **ربط الحساب**: المستخدم ينقر على \"ربط Instagram\" ويتم إعادة توجيهه للتفويض\n2. **حفظ البيانات**: يتم حفظ الـ access token بشكل آمن في قاعدة البيانات\n3. **التحديث**: يتم تحديث الـ token تلقائياً قبل انتهاء الصلاحية\n4. **القطع**: يمكن قطع الاتصال في أي وقت\n"
