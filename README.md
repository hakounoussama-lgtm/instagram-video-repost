# Instagram Video Repost Application

تطبيق لتحميل الفيديوهات من حساب Instagram ونشرها على حسابك.

## المميزات
- ✅ تحميل الفيديوهات بالأوصاف والهاشتاغات
- ✅ نشر تلقائي على حسابك
- ✅ واجهة ويب سهلة الاستخدام
- ✅ حفظ البيانات في قاعدة البيانات
- ✅ دعم العربية

## التثبيت

### المتطلبات:
- Python 3.8+
- pip

### خطوات التثبيت:

```bash
# 1. استنساخ المستودع
git clone https://github.com/hakounoussama-lgtm/instagram-video-repost.git
cd instagram-video-repost

# 2. إنشاء بيئة افتراضية
python -m venv venv

# Linux/Mac
source venv/bin/activate

# Windows
venv\Scripts\activate

# 3. تثبيت المكتبات
pip install -r requirements.txt

# 4. إنشاء مجلدات العمل
mkdir -p downloads uploads

# 5. تشغيل التطبيق
python app.py
```

### الوصول للتطبيق:

افتح المتصفح واذهب إلى:
```
http://localhost:5000
```

## طريقة الاستخدام

1. **أدخل بيانات حسابك**:
   - اسم المستخدم (username)
   - كلمة المرور (password)

2. **أدخل رابط الحساب المستهدف**:
   - مثال: `https://instagram.com/username`

3. **اضغط على زر "ابدأ إعادة النشر"**

4. **انتظر انتهاء العملية**
   - سيتم تحميل الفيديوهات
   - ثم نشرها على حسابك تلقائياً

## ملاحظات أمنية

⚠️ **لا تشارك بيانات دخولك مع أحد**
- احفظ كلمة المرور في مكان آمن
- استخدم كلمات مرور قوية
- لا تنسخ الكود في أماكن غير آمنة

## استكشاف الأخطاء

### خطأ: "فشل تسجيل الدخول"
- تأكد من صحة بيانات الدخول
- تحقق من اتصال الإنترنت
- قد تحتاج Instagram إلى التحقق من الجهاز

### خطأ: "الحساب المستهدف غير موجود"
- تأكد من صحة رابط الحساب
- جرب بدون `https://` و `www`

### خطأ: "المكتبات غير مثبتة"
```bash
pip install -r requirements.txt
```
